## S7-04 Telegram Bot — точный остаток

Команды, генерации, подписки и восстановление после сбоев уже подтверждены. Ошибкой пункт держит одно: **удаление Telegram-аккаунта нельзя выполнить**.

- В API `accept_confirmed_request` вызывается только с `ecosystem="website"` (`services/account_identity.py`:1327). Маршрута, который принимает запрос для Telegram, нет.
- Флаг `SYLVEX_ERASURE_TELEGRAM_READY` (=0) лишь разрешает такой приём; включение флага само ничего не даёт.
- В основном боте команды `/delete` нет. `RIGHTS_COMMANDS` только пропускает её во время уже принятого удаления. Очистка кэша бота после принятого удаления (`forget_loop`, `telegram_caches_cleared_at`) уже есть.
- Поддержка выполнить обещанное удаление не может: инструмента нет, а ручной SQL недопустим.

Native-оплата Stars ошибкой S7-04 не является, она учтена в S8-02.

## S8-08 Data Retention — точный остаток

| Данные | Сейчас | Соответствие |
