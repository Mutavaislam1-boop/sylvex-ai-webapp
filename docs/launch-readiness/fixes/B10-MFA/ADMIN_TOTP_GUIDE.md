# Двухфакторная аутентификация (2FA) для администраторов SYLVEX

После внедрения код 2FA нужен во всех каналах: в Mini App «SYLVEX Admin», в браузере и в ботах.

**Не отправляйте код в чат.** Его вводят только в окне «SYLVEX Admin». Боты сами никогда не просят прислать код сообщением.

## 1. Подключение (один раз)

1. Установите приложение-аутентификатор: Google Authenticator, 1Password, Authy или аналог.
2. Откройте Telegram → бот поддержки SYLVEX → кнопка **«🖥 SYLVEX Admin»**.
3. Если 2FA ещё не настроена, консоль покажет «Двухфакторная аутентификация обязательна…».
   - Если сначала появилось поле кода, нажмите «Я ещё не настроил аутентификатор».
4. Нажмите **«Настроить аутентификатор»**.
   - Если прошло больше 5 минут после входа, консоль попросит «Подтвердить через Telegram». Это только для настройки, другие функции такое подтверждение не открывает.
5. Отсканируйте QR-код приложением (или введите ключ вручную) и введите 6-значный код из приложения → **«Включить»**.
6. Консоль откроется полностью. Боты могут действовать от вашего имени следующие 30 минут.

Подключить 2FA можно только из Telegram Mini App. Так браузерный доступ остаётся привязан к вашему Telegram-аккаунту. Исключение одно: владелец с подтверждённым `ADMIN_OWNER_EMAIL` может настроить 2FA при первом входе в браузере.

## 2. Ежедневная работа

| Где | Что нужно |
|---|---|
| Mini App «SYLVEX Admin» | Telegram + код 2FA при каждом входе |
| Браузер | email + пароль SYLVEX + код 2FA |
| Критическое действие в консоли (права администраторов, рассылка, цены, модели, возвраты, удаление) | повторный код 2FA, действует 5 минут |
| Бот поддержки, основной бот (`/admin`, `/addbalance`) | подтверждение кодом 2FA в Mini App: 30 минут, для критических действий и `/addbalance` — 5 минут |

Когда бот пишет «🔐 Подтвердите вход кодом 2FA»:
1. Нажмите **«🔐 Подтвердить 2FA»**.
2. Введите код в открывшемся окне.
3. Нажмите «Вернуться в бот» и повторите действие.

«Выйти везде» (Аккаунт и безопасность) завершает все сессии консоли и подтверждение для ботов.

## 3. Ошибки кода

- **Неверный, старый или повторно использованный код** не принимается. Каждый код действует один раз и около 30 секунд.
- **5 неверных кодов подряд** блокируют ввод на 15 минут. Это защита, а не поломка.
- **Неверные коды и вход с нового устройства** записываются в журнал. Администратор и владелец получают уведомление в Telegram.

## 4. Потеря телефона с аутентификатором

- **Администратор (не владелец):** владелец открывает «Администраторы» → **«Сбросить 2FA»** у этого администратора и указывает причину. Нужен свежий код 2FA владельца. Все сессии администратора завершаются. Затем администратор снова проходит раздел 1.
- **Владелец:** сам себе 2FA сбросить нельзя, иначе захвата одного Telegram-аккаунта хватало бы для обхода. Варианты:
  - **Заранее:** сохраните резервную копию ключа (ключ показывается при настройке) или добавьте второго владельца.
  - **Восстановление через базу.** Это делает только владелец с доступом к Railway → Postgres → Query; `<ID>` — номер строки владельца в `admin_accounts`:
    ```sql
    UPDATE admin_accounts
       SET totp_secret_enc = NULL, totp_pending_enc = NULL, totp_enabled_at = NULL,
           totp_last_step = NULL, totp_failures = 0, totp_locked_until = NULL, telegram_confirmed_at = NULL
     WHERE id = <ID> AND role = 'owner';
    UPDATE admin_sessions SET revoked_at = NOW() WHERE admin_id = <ID> AND revoked_at IS NULL;
    ```
    После этого откройте «SYLVEX Admin» в Telegram и пройдите раздел 1.

## 5. Почему никто не окажется заблокирован при включении

- **Администратор без 2FA** не теряет доступ, но и в консоль не попадает. Mini App выдаёт ему сессию, в которой доступна только настройка 2FA. Первый подтверждённый код превращает её в обычную сессию. Это проверено тестом для всех ролей, включая владельца.
- **Действующие сессии Mini App** после развёртывания попросят ввести код. Браузерные сессии уже прошли 2FA и продолжают работать.
