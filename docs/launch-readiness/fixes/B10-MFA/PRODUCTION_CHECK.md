## Безопасная ручная проверка оставшегося (без изменения балансов и данных)

1. **Бот поддержки.**
   - «Аккаунт и безопасность» → «Выйти на всех устройствах».
   - В боте поддержки открыть «Дашборд». Ожидаемо: «🔐 Подтвердите вход кодом 2FA» и кнопка «🔐 Подтвердить 2FA».
   - Нажать кнопку, ввести код → «Вернуться в бот» → «Дашборд» открывается.
2. **Основной бот.**
   - Сразу после «Выйти на всех устройствах» отправить `/admin`. Ожидаемо: кнопка «🔐 Подтвердить 2FA», статистики нет.
   - Подтвердить в открывшемся окне и снова отправить `/admin`. Ожидаемо: «Пользователей: …».
   - `/addbalance` **не** отправлять.
3. **Критическое действие.**
   - Через 5 минут после входа: «Администраторы» → «Изменить» у не-владельца → «Сохранить» без изменений, причина «B10 проверка».
   - Ожидаемо: окно «Подтвердите, что это вы» только с полем кода.
   - Ввести `000000` → «Код неверный»; затем верный код → сохранение. Значения не меняются, в аудит пишется только запись о проверке.
4. **Третий администратор:** открыть SYLVEX Admin → настроить 2FA → консоль открывается.
